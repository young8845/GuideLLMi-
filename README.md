# GuideLLM基准测试实操
一、 延迟指标（Latency）—— 决定“用户卡不卡”
这一组指标衡量的是单次请求的速度。数值越小越好。

英文指标	中文含义	解释与通俗比喻
TTFT：首字延迟 (Time to First Token)	从用户按下发送，到屏幕上蹦出第一个字的时间。（像你点外卖后，等骑手接单的时间）。单位通常是毫秒(ms)。
ITL：字间延迟 (Inter-Token Latency)	模型在“吧嗒吧嗒”吐字时，相邻两个字之间的间隔时间。（像打字机的敲字速度）。决定了文字输出是否流畅。
TPOT；单字生成耗时 (Time Per Output Token)	生成每一个字平均需要花多少时间。和 ITL 类似，但计算维度略有不同（通常包含整个生成阶段）。
Request Latency	总延迟	从发请求到模型把最后一个字吐完，总共花了多少时间。（外卖从下单到送达的总时间）。
P95 / P99	95/99 分位数	极度重要的工业指标。代表有 95%（或 99%）的请求，延迟都低于这个值。用于排查“长尾卡顿”（如果 P95 远高于均值，说明少数用户被卡得很惨）。
二、 吞吐量指标（Throughput）—— 决定“老板省不省钱”
这一组指标衡量的是整个系统的产能。数值越大越好。
英文指标	中文含义	解释与通俗比喻
Concurrency	并发数	同一时刻，服务器正在同时处理的请求数量。（店里同时有多少桌客人在吃饭）。
Requests Per Sec (QPS)	每秒请求数	你的系统一秒钟能完整处理（回答完）几次对话。（餐厅一秒钟能翻几次台）。
Input Tokens / Sec	输入吞吐量	服务器一秒钟能“读”进去多少个字（Prefill 阶段）。
Output Tokens / Sec	输出吞吐量	🔥 最核心的指标！ 服务器一秒钟总共能生成多少个字。（整个后厨一秒钟能炒出多少盘菜）。直接决定了你需要买多少张显卡。
Total Tokens / Sec	总吞吐量	一秒钟内，输入 Token 数 + 输出 Token 数 的总和。
